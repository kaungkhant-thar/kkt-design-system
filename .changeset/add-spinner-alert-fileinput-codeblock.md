Add Spinner, Alert, FileInput, and CodeBlock components

- **Spinner**: standalone loading indicator with `sm/md/lg` sizes and `default/accent/white` variants; `role="status"` with configurable `aria-label`
- **Alert**: inline message banner with `info/success/warning/error` variants, optional title, and optional dismiss button; `role="alert"` for screen readers
- **FileInput**: styled file picker with drag-and-drop support, file list with per-file removal, `multiple` and `accept` props, and the same `label/helperText/error` API as Input
- **CodeBlock**: monospace code display with language label, copy-to-clipboard button (flips to "✓ Copied" for 2 s), and `showCopyButton` toggle
